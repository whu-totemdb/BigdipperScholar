# 基于多模数据的综合分析技能

## 1. 适用场景

机构或团队比较、核心学者识别、年度趋势、作者/机构合作分析、专家与合作者推荐。目标是形成有统计口径、有代表实例、可追溯到实体和关系的分析。

## 2. 所需数据

从 MCP 模式确认论文、作者、机构、主题及 venue 的标识和跨模型映射。按任务获取关系属性与统计字段、署名/合作/引用图、代表工作的摘要文档以及主题相关性的库内向量结果。明确时间、主题、venue、统计单位、排序指标和结果形式。

## 3. 推荐步骤

1. 解析分析对象和约束，明确“发文”“合作”“影响力”等指标的定义。
2. 构造候选论文集合：关系条件限定范围；需要语义匹配时用库内向量检索，并核对题名与摘要。
3. 在统一数据库中完成连接、去重、分组与排序。论文数按论文 ID 去重，作者/机构数按各自 ID 去重。
4. 用图关系检查署名归属、合作和引用联系，分析总量与结构差异。
5. 补齐代表论文的摘要、作者和机构，区分统计事实与内容解释。
6. 核对分组与合计、双方口径及候选覆盖，修正查询并关联结果分析。
7. 保留统计依据、代表论文及支持解释的关系与文档，确认最终有效集合。

## 4. 可复用 MMSQL 方案

| 方案 | 查询组合 | 内置 CN 工具示例 |
| --- | --- | --- |
| 年度/venue 产出 | 机构论文 → 年份与 venue → 按论文去重分组 | `aggregate_papers_by_venue`、`search_papers_by_venue` |
| 核心学者 | 主题候选 → 署名图 → 按作者聚合排序 | `get_institution_field_author_rank`、`get_field_top_authors` |
| 合作分析 | 共同署名/合作图 → 作者或机构对 → 共同论文数 | `get_field_institution_collaboration_graph` 或通用 MMSQL |
| 候选推荐 | 主题/语义候选 → 署名与机构条件 → 匹配作者及论文 | `recommend_institution_experts_for_paper` 或通用 MMSQL |
| 代表作解释 | 排名结果 → 属性、摘要、作者机构 | `get_paper_metadata_batch` |

通用组合为“候选 CTE → 图或关系连接 → 按实体去重聚合 → 连接展示字段”。先定义统计集合再计算指标；展示 Top-k 不改变全量统计的分母。仅调用当前已注册工具。

## 5. 结果检查规则

- 比较对象使用相同的时间、主题和 venue 口径，会议与同名期刊按实际映射区分。
- 避免署名、多主题连接的重复计数；区分全量统计和语义 Top-k/工具候选上限内的样本统计。
- 保留过滤条件、分母和排序指标；分组与合计一致，跨组重叠时说明去重方式。
- 共同发表、共同主题和语义相近分别描述；共享主题不证明合作，单篇署名不证明固定团队。
- 失败、空结果、旧口径、重复材料及依赖已排除观察的联合分析不进入最终生成。

## 6. 停止条件

主要指标、比较维度和代表实例已有依据，统计口径一致时结束。无法获得完整覆盖时明确范围和缺口，不无限扩展。用 `finalize` 提交完整有效集合，交由报告和证据智能体组织结果。
