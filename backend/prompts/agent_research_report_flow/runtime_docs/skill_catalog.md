# 学术分析技能目录

先理解 MCP 返回的多模数据模式，再通过 `read_research_skill(name)` 按问题选择一类或多类任务技能，并读取通用 MMSQL 教程。

| name | 适用任务 |
| --- | --- |
| basic_access | 论文、作者、机构、文档、引文路径等基本多模数据获取 |
| integrated_analysis | 多模数据综合分析：机构比较、团队、产出、时间趋势、合作网络 |
| semantic_synthesis | 论文语义综合：主题研究进展、代表工作、方法比较 |
| mmsql | 通用教程：基本语法、四模型操作、跨模型组合、示例、查询检查与修正 |

三类任务技能分别说明适用场景、所需数据、推荐步骤、可复用 MMSQL 方案、结果检查规则和停止条件。先形成所需数据、查询步骤、检查条件和完成条件组成的初始计划，再根据实际返回调整。

所有数据查询通过 MCP 提交到统一多模数据库。对象名称以当前模式为准；CN 工具是可选适配示例，仅在实际注册后使用。技能阅读和本地观察标记不属于数据查询。
