# 基本多模数据获取技能

## 1. 适用场景

围绕论文、作者、机构或主题，定位实体，获取属性、文档内容、局部结构关系或语义相似对象。例如查询论文及其作者、某作者的论文、参考文献或种子论文的相似工作。

## 2. 所需数据

先读取 MCP 返回的多模数据模式，将用户对象映射到统一实体 ID。按问题选择关系属性（名称、题名、年份等）、图模式与边方向、文档字段（摘要、作者列表等）、向量对象及其实体映射、模型和距离度量。所有数据查询提交到同一个多模数据库；embedding 服务只生成查询向量。

## 3. 推荐步骤

1. 明确对象、时间范围、所需属性、关系方向和输出数量，形成查询计划与完成条件。
2. 用名称、题名或已有 ID 定位实体，以统一 ID 连接各模型表示；多个匹配时保留可区分的属性。
3. 获取所需属性或文档；问题需要关系时查询相应图模式，需要相似对象时执行库内向量检索。
4. 为邻居和相似结果补齐题名、年份、摘要及必要的署名信息。
5. 分析返回结果并关联 observationIds；根据缺失字段或错误修正下一步查询。
6. 检查用户要求的覆盖情况，最终确认有效观察集合。

## 4. 可复用 MMSQL 方案

| 方案 | 输入与输出 | 内置 CN 适配工具示例 |
| --- | --- | --- |
| 实体定位 | 题名/名称 → 实体 ID 与属性 | `papertitle_2_paperid`、`authorname_2_authorid`、`get_institution_id` |
| 属性与文档补全 | paperid 集合 → 题名、年份、摘要、署名 | `get_paper_metadata_batch` |
| 署名关系 | paperid → 作者、机构与署名属性 | `get_paper_author_affiliations_graph` |
| 引用关系 | paperid、方向 → 引用端点 | `expand_paper_citations` |
| 语义相似 | 自然语言/种子 paperid → paperid、分数、排名 | `search_papers_by_natural_language`、`find_similar_papers_by_paperid` |

组合模式：关系定位种子 → 图邻居 → 连接关系和文档；或库内向量 Top-k → 元数据补全。只使用实际注册工具；没有封装时，读取 `mmsql` 教程后通过通用接口生成查询。示例表名映射到当前模式。

## 5. 结果检查规则

- ID、时间和条件与任务一致，同名对象不自动合并；关系端点和方向来自实际结果。
- 相似结果保留度量、分数、排名和查询/种子来源；同批召回不代表论文之间相似。
- 区分查询为空、执行失败和字段缺失；只有摘要时仅作摘要层面分析。
- 最终集合只含成功、非空、相关、可追溯且有信息增量的观察；联合分析的全部来源应在集合中。

## 6. 停止条件

所需对象、属性和关系已覆盖，关键字段可追溯，后续查询没有必要的信息增量时结束。数据不足或达到执行上限时明确缺口，不补造结果。调用 `select_report_observations(mode="finalize")` 提交完整有效集合。
