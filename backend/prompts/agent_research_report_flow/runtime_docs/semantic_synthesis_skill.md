# 论文语义综合分析技能

## 1. 适用场景

围绕研究主题总结进展、代表方向、方法差异、论文及作者团队。适用于只给出主题描述，需要从多个相关工作形成综合解释的任务。

## 2. 所需数据

读取 MCP 模式中的论文关系属性、文档结构、引用与署名图、库内向量对象及模型信息。通常需要 paperid、题名、年份、venue、摘要、作者机构、引用端点、实际语义分数和来源。时间与主题约束贯穿候选获取和扩展。

## 3. 推荐步骤

1. 将主题拆为核心概念、相邻概念和用户关心的分析维度，形成初始计划和完成条件。
2. 生成查询向量，在统一多模数据库内召回候选；用题名关键词、主题或 venue 条件补充候选。
3. 补齐题名、年份、摘要和署名，判断任务相关性，选择代表性种子论文。
4. 按信息缺口扩展：查询参考文献/被引，或基于种子向量查相似论文；某作者持续研究同一问题时，可以沿署名查询其其他论文，再核查内容相关性。
5. 记录扩展起点、关系类型、条件和结果。新候选仍须接受时间和内容检查，不因一次扩展自动成为代表作。
6. 基于实际摘要比较问题、方法、应用、贡献与局限，形成方向或时间阶段，补齐团队信息。
7. 检查值得补查的缺口，根据返回结果修正计划，关联分析来源，确认最终有效集合。

## 4. 可复用 MMSQL 方案

| 方案 | 查询组合 | 工具示例 |
| --- | --- | --- |
| 主题召回 | 查询向量 → 库内 Top-k → 关系条件与文档 | `search_papers_by_natural_language`、`get_paper_metadata_batch` |
| 种子语义扩展 | 库内种子向量 → 相似论文与分数 → 内容核查 | `find_similar_papers_by_paperid` |
| 引用扩展 | 种子 → 有向引用邻居 → 元数据/摘要 | `expand_paper_citations` 或通用 MMSQL |
| 作者线索扩展 | 种子 → 署名作者 → 其他论文 → 时间和主题检查 | 署名图查询与通用 MMSQL |
| venue 补充 | venue/时间/机构 → 关键词或摘要相关性 | `search_papers_by_venue`、`search_papers_by_keywords` |

按任务需要组合，不必执行全部路径。只调用已注册工具；其他需求按 `mmsql` 教程生成查询。

## 5. 结果检查规则

- 区分 query-to-paper 召回和 paper-to-paper 相似；同批召回不能自动生成相似边。
- 引用方向、署名路径和相似分数来自实际结果，保留种子和端点。
- 相关性由内容检查支持，不能只凭宽泛领域标签或高相似分数判断贡献。
- 只有摘要时仅解释摘要支持的内容，不声称读取全文或未返回的实验指标。
- 团队介绍根据署名、机构和研究内容，不从姓名推断职称或长期组织关系。
- Top-k 不是领域全集；说明代表作选择依据和覆盖缺口。缺失记录不能解释为没有研究。
- 最终结论能指向成功、相关、可追溯且有信息增量的观察，联合分析的全部来源均保留。

## 6. 停止条件

用户要求的方向、代表工作和团队已有足够内容及关系支撑，继续扩展的信息增量有限时结束。覆盖不足则说明缺口。通过 `finalize` 提交完整有效集合，报告和多模证据使用同一组来源。
